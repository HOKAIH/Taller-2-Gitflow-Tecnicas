# Taller-2-Gitflow-Tecnicas

# Análisis de enunciado:
El código del estudiante debe cumplir tres condiciones obligatorias:

Tener exactamente 8 caracteres.

Iniciar con la letra "E".

Los 7 caracteres restantes deben ser numéricos (0–9).

Esto significa que el formato válido es:
Ejemplo válido:
E1234567


# Técnica adecuada y justificación

La técnica más adecuada es partición de Equivalencia porque podemos dividir los datos en clases válidas e inválidas y no necesitamos probar todos los posibles códigos, solo representantes de cada clase.

# Aplicación de técnica

| Encabezado 1 | Encabezado 2 | Encabezado 3 |
| :--- | :---: | ---: |
| Fila 1, Col 1 | Fila 1, Col 2 | Fila 1, Col 3 |
| Fila 2, Col 1 | Fila 2, Col 2 | Fila 2, Col 3 |
